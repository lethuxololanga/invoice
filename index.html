        Import into Zoho Books

        1. In Zoho Books go to Sales → Invoices → ⋯ → Import Invoices.
        2. Choose the file you just downloaded.
        3. On the next screen untick “Auto-generate invoice numbers” to keep your numbers.
        4. Let it match customers by name. Create any missing customers in Zoho first, or turn on the option to create them if you see it.
        5. Check Map Fields, then import.

        Invoices come in as drafts. Payments and credit notes aren’t included. If VAT is on, Zoho needs a tax named “VAT” set up (it can’t be used if your organisation isn’t VAT-registered).

        Everything stays in this browser — no account, nothing uploaded. Clearing your browser data deletes your invoices, so export a backup now and then.
